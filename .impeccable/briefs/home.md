# Surface brief: home (public/index.html)

Scope: the Pixmith landing page. Mode: Persuade. Audience: pixel artists and indie game devs who already use
Aseprite and build in Godot; English and Bahasa Indonesia (toggle). Action: download the build for their OS.
Proof: the real editor screenshots, real .aseprite/Godot facts, an interactive Live Link demo (labelled demo).
Hosting: undecided (repo is private); the deployable folder is public/.

## Direction contract

THESIS: The page is a 16-bit RPG the visitor is already playing: a living pixel-art night scene with a JRPG dialogue
box and a cursor menu whose choices are the real actions. It refuses the dark-SaaS template the first draft fell into
(headline + button left, product right, icon cards below).

OWN-WORLD: SNES-era JRPG menus: deep-blue window fills (#2d3aa8 to #121a63) inside an authored white pixel frame with
notched corners, a white ▶ cursor, Pixelify Sans for every window title, menu item and dialogue line; Bricolage
Grotesque only for long reading text; Pixmith's ramp (violet, blue, pink, coral, amber) as the night scene's light.
Grounds are night-sky purple (#1b1538) with the editor checkerboard as texture.

STORY: I am inside a game made of pixels; the character says what Pixmith does; the menu lets me download for my OS
at once; scrolling, I play the Live Link demo, browse the inventory of features, read install tips, and save.

FIRST VIEWPORT: Full-bleed canvas scene (384x216 art scaled crisp, parallax hills, inn with lit windows, stars,
fireflies, the hero on the ground). Top: a slim status window (PIXMITH, LV <version>, EN/ID). Bottom-left 2/3: the
dialogue window typing the headline and sub. Bottom-right 1/3: the menu window, cursor on "Download for <OS>".

FORM: JRPG menu grammar carried across nav, actions, sections and states (own pick; launcher unavailable).
seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
